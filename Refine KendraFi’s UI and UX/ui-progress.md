## Diamond Record (Rule of Three)

### Round 1 · Directions (Hero Screen: `Command Center`)

- **A · Sovereign Ledger (`PICKED — Recommended`):** Warm archival paper canvas (`#F4F2EC`), `Newsreader` + `DM Sans` + `IBM Plex Mono` + `Noto Sans Bengali`, top 4-stage live FSM pipeline rail, 3 balanced stage cards with progressive proof drawers, and an interactive 5-node Kendra Pentagon. _Why picked:_ Eliminates AI-slop SaaS tropes while preserving KendraFi's light-theme mandate and 3-stage causal clarity.
- **B · Nocturnal Risk Terminal (rejected):** High-contrast dark slate (`#0D1210`) with neon telemetry. _Why rejected:_ Drifts into crypto-trading aesthetics and breaks KendraFi's accessible light-canvas identity.
- **C · Split Passbook & Inspector (rejected):** Two-column master-detail list + single detail pane. _Why rejected:_ Hides simultaneous side-by-side causality between merchant voice intent, peer staking, and zero-trust escrow.

### Round 2 · Variations (Inside `A · Sovereign Ledger`)

- **A1 · Reconciled Deal Strip:** Pushes hierarchy with an always-visible horizontal balance reconciliation bar (`Principal -> APR -> DSCR -> Coverage -> Net Supplier Payout`).
- **A2 · Kinetic Node-Inspector Pentagon:** Pushes signature interaction—clicking any of the 5 merchant nodes (`AGT-01`..`AGT-05`) reveals live buffer capital, inflow volatility `CV`, Besley-Coate share, and utility while SVG packets traverse active chords.
- **A3 · Sovereign Synthesis (`WINNER — Recommended`):** Combines A1's reconciled deal strip + progressive proof drawers with A2's interactive 5-node Pentagon, bilingual studio voice equalizer, and refined editorial rhythm.

### Round 3 · Critique & Fixes Applied

1. **Purged all `<12px` micro-fonts:** Replaced legacy `7px–10px` CSS rules with a strict `>= 12px` (`0.75rem`) scale and `tabular-nums`.
2. **Progressive disclosure enforced:** Moved raw OCR text, 10-message CNP round logs, 16-bit secp256k1 commitment points, and 65-byte EIP-712 hex signatures into clean tabs and accordions.
3. **Causal 4-stage execution choreography:** Added cancel-safe sequential FSM stepping (`Perception -> Audit -> Syndicate -> Settlement / Quarantine / Bailout`) with live latency telemetry.
4. **WCAG AA & mobile ergonomics:** Verified `>= 4.5:1` text contrast, `40px+` touch targets, keyboard `aria-pressed` / `aria-expanded` states, and `prefers-reduced-motion` support.
